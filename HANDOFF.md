## 0. Как запустить прямо сейчас

```bash
cd ds-analyzer
npm install
npm run analyze -- /path/to/your-project
```

Пишет в `<project>/ui-analyzer/`: `dashboard.html` (открыть двойным кликом), `findings.json`, `usage.json`, `summary.json`, `project-profile.json`, `.cache/observations.json`.

| Флаг | Зачем |
|---|---|
| `--kit-package @company/ds` | кит опубликован под своим именем |
| `--exclude 'src/legacy/**'` | добавить исключения (синтаксис .gitignore) |
| `--out <dir>` | писать не в проект |
| `--artifacts <dir>` | другая версия спеки кита |

`npm run verify` — typecheck + lint + 500 тестов. `npm run scan` — только стадии B0+B, без правил.

**Что уже прогонялось:** `demo-app`, весь `ui-kit-eds-ce` (2378 файлов, yarn workspaces, 9 алиасов, 0 непрочитанных файлов, 8 с), сам `ds-analyzer` (честно отвечает «кит не используется»), синтетический Next.js app-router без `src/`, без tsconfig, на `.jsx`, с переименованным китом.

### Чего пока нет

Детектор кастомных компонентов (`component.custom` / `.novel` / `.fork` / `.duplicate`) и `icon.inline-svg`. Ожидания под них лежат в оракуле со `stage: "M5"` и в подсчёт precision/recall не входят. Экран «Кандидаты в дизайн-систему» появится вместе с ними.

## 1. Что это за проект

Двухчастная система вокруг дизайн-системы `sds-eng`:

1. **Извлечение спеки кита** → машиночитаемые JSON-артефакты. **Готово.**
2. **Анализ продуктовых проектов** на отклонения от этой спеки, с дашбордом и ИИ-подсказками. **Сканер, правила и дашборд готовы; детектор кастомов и ИИ-слой — нет.**

Конечная цель: разработчик в Claude Code пишет `/ds-audit`, получает `ui-analyzer/dashboard.html` со всеми отклонениями, диффами и предложениями замен.

## 5. Ключевые технические решения, которые надо знать

### 5.1 Тема кита исполняется, а не парсится

`packages/theme` не имеет **ни одного** внешнего импорта. Загрузчик собирает её esbuild'ом и импортирует как `data:`-URL, получая и авторские шаблоны `{edsRef.…}`, и разрешённые значения. Это исключает переписывание `calcTheme()` и расхождение реализаций.

Плагин `record-external-imports` **валит экстракцию**, если в теме появится внешний импорт. Если это случится — предпосылка сломалась, надо менять подход, а не «чинить» ошибку.

### 5.2 Компоненты разбираются чисто синтаксически

`node_modules` кита не установлены → тайпчекера нет. ts-morph грузится с `noResolve` и `skipFileDependencyResolution`. Всё, что требует межпакетных типов, помечается как пробел, а не угадывается.

Следствия, зафиксированные в артефакте:
* `meta.typeCheckerAvailable: false`
* 25 пакетов `@v-uik` реэкспортируются звёздочкой и не перечислимы → `publicSymbols` (462) это **нижняя граница** публичного API
* `props-type-not-found` для 3 публичных компонентов

Всё это закрывается установкой зависимостей кита, **без изменения контрактов**.

### 5.3 Артефакты детерминированы

Ни одной временной метки. Сортировка по код-юнитам, не `localeCompare` (зависит от локали машины). Побайтовая воспроизводимость закреплена тестом. Метаданные запуска вынесены в `extraction-summary.json`.

### 5.4 Демо-файлы кита исключены из API-спеки

`*.stories.tsx`, `examples/`, `doc/` загружаются (нужны для резолвинга и инвентаря), но не участвуют в обходах API. Без этого «компонентов» было бы 956 вместо 168.

## 9. Что делать первым

**M5 — детектор кастомных компонентов.** Вход для него готов: `observations.declarations[]` уже несёт `ariaRoles`, `ariaAttributes`, `nativeTags`, `jsxShape`, `props`, `cssProperties`, `kitComponentsUsed`, `hasInlineSvg` и `astSignature` (нормализованный поток токенов для MinHash). Пересобирать AST не нужно — коллекторы единственная стадия, которой позволено трогать синтаксис.

### Решения, принятые по ходу и расходящиеся с `architecture.md`

| Что | Как в доке | Как сделано и почему |
|---|---|---|
| Калибровка на примерах кита | «0 находок на 684 примерах» | Недостижимо и неверно: примеры — демо-обвязка с сырыми значениями. Заменено на **0 срабатываний API-правил** — измеримо и зафиксировано тестом |
| Размерные правила | «любой числовой литерал» | Только свойства, у которых есть замена. `width`/`margin`/`inset`/`min-*` исключены: токена под них не существует |
| Выбор токена при точном совпадении | «sys, если есть; иначе ref» | Уточнено ролью свойства: sys-роль совпала → sys; иначе ref; кросс-ролевой sys — последним. Плюс `*Const`-группы понижены, когда роль неизвестна |
| Поиск ближайшего токена | ΔE в OKLab | Плюс фильтр по альфе: ΔE считается по RGB и не видит прозрачность, из-за чего тень 12 % «точно совпадала» с плотным цветом |
| `style.override.*` | одна находка на объявление | Одна на (класс, категория). И приватный слот — нарушение при **любом** свойстве, включая раскладку |
| Корень цепочки SCSS-переменных | не оговорено | Самое глубокое объявление: чинить надо строку с литералом, а не промежуточную |
| Размер дашборда | «1.2–1.8 МБ» | Держится для обычного проекта: 931 КБ шаблона + ~3,2 КБ на находку. Репозиторий кита (1591 находка) — 6 МБ |
| shadcn/ui | через CLI | Примитивы скопированы вручную — shadcn это и есть копирование внутрь. Radix не понадобился; Recharts, react-diff-viewer-continued и @tanstack/react-virtual взяты как настоящие зависимости |
