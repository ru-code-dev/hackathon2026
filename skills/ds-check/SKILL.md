# ds-check — что вносит этот дифф

Полный анализ проекта, но вердикт — **только по изменённым строкам**: разработчик отвечает
за свой дифф, а не за весь накопленный долг. Правила стабильности те же, что в ds-audit:
команды дословно, при ошибке — показать вывод и остановиться, числа брать только из JSON.

## Шаг 1 — что сравниваем

`PROJECT_DIR` — текущий каталог (`pwd`); проект обязан быть git-репозиторием.
Выбор диапазона по словам пользователя:

- ничего не уточнил / «мои изменения» → без флагов (рабочее дерево + индекс против HEAD)
- «только staged» → добавь флаг `--staged`
- назвал ветку или диапазон («против main», «origin/main..HEAD») → `--range <диапазон>`

Если пользователь назвал ветку без диапазона, диапазон = `<ветка>..HEAD`.

## Шаг 2 — запуск

```bash
node "$HOME/.qwen/skills/ds-audit/scripts/ds.mjs" check "<PROJECT_DIR>"
```

(при необходимости добавь `--staged` ИЛИ `--range <диапазон>` — вместе нельзя).
Команда может работать до нескольких минут — жди.

Маркер успеха: JSON в stdout с полем `"$schema": "ds-analyzer/check@1"`.
Прогресс анализа идёт в stderr — это нормально, читай только JSON из stdout.
Код возврата ≠ 0 → покажи последние 20 строк вывода и остановись.

## Шаг 3 — вердикт пользователю

Строго из полей JSON, по-русски:

- Если `totals.findings` = 0: «Чисто: изменения (`changed.files` файлов,
  `changed.lines` строк) не вносят отклонений от дизайн-системы.»
- Иначе: «Дифф вносит `totals.findings` отклонений (`totals.errors` ошибок,
  `totals.warnings` предупреждений) в `changed.files` файлах; решений —
  `totals.decisions`, авто-фикс — `totals.autoFixable`.»
- Перечисли до 10 первых из `findings`: `файл:строка — actual → expected (rule)`;
  если `omitted` > 0 — допиши «…и ещё N, полный список в дашборде».
- Дашборд — ОБЯЗАТЕЛЬНО кликабельной markdown-ссылкой (если `artifacts.dashboard` не null):
  `[Открыть дашборд — режим «только изменения»](file://<artifacts.dashboard>)`
  (дашборд сам откроется отфильтрованным по этому диффу).

## Шаг 4 — что дальше

Если `totals.autoFixable` > 0 — задай вопрос `ask_user_question`:

- Вопрос: «Что дальше?»
- «Применить автофиксы диффа (ветка + коммит + пуш)» → выполни скилл **ds-fix**
- «Закончить» → останься в ожидании.

Иначе просто сообщи, что автофиксов для этих строк нет.

## Для CI (если спросят)

Тот же вызов с флагом `--gate` возвращает код 1, когда на изменённых строках есть ошибки:
`node …/ds.mjs check "<PROJECT_DIR>" --range origin/main..HEAD --gate`
