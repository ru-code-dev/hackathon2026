# ds-analyzer

Извлекает спецификацию дизайн-системы `sds-eng` (`ui-kit-eds-ce`) в машиночитаемые JSON-артефакты.

Артефакты — промежуточное представление для будущего анализатора продуктового кода: он сопоставляет код проекта со спекой кита и находит отклонения (хардкод цветов и размеров, чужие шрифты, переопределения стилей, кастомные компоненты).

Спецификации: [`../SPECS/`](../SPECS/)

---

## Запуск

```bash
npm install

npm run extract              # оба экстрактора → artifacts/
npm run extract:tokens
npm run extract:components

npm run verify               # typecheck + lint + tests
npm run test:coverage
```

Путь к киту: аргумент → `DS_UI_KIT_ROOT` → `../ui-kit-eds-ce`.

`node_modules` кита устанавливать **не нужно** — экстракторы работают на чистом клоне.

## Артефакты

| Файл                                | Содержимое                                                                        |
| ----------------------------------- | --------------------------------------------------------------------------------- |
| `artifacts/tokens.json`             | 2192 токена трёх тиров, шкалы, обратный индекс `значение → токен`, диагностики    |
| `artifacts/components.json`         | 61 компонент, 462 публичных символа, варианты, слоты, пропы, обёртки над `@v-uik` |
| `artifacts/extraction-summary.json` | Метаданные запуска: время, длительности, сводка диагностик                        |

`tokens.json` и `components.json` **детерминированы** — без временных меток, с устойчивой сортировкой. Два запуска дают побайтово идентичный файл (закреплено тестом), поэтому их можно коммитить и осмысленно диффить между версиями кита.

## Тесты

254 теста, 23 файла. Покрытие ≈ 97 % строк (пороги — 80 %).

- **Юнит-тесты** — каждый чистый модуль, включая граничные случаи и отказы.
- **Интеграционные** (`tokens/extract.test.ts`, `components/extract.test.ts`) — на реальном ките: полнота (ни один лист темы не потерян), достоверность (значения совпадают с `calcTheme()`), обратимость индексов, детерминизм, соответствие схеме.
- **Тесты загрузчика** — на временных фикстурах: падает ли загрузчик, если тема перестала быть самодостаточной.

- 44 семантических цвета одинаковы в светлой и тёмной теме
